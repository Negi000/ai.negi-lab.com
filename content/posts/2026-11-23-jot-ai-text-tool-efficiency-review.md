## 結論から: このツールは「買い」か

結論から言うと、Macをメイン機として使い、ライティングやメール、コードのドキュメント作成に追われている人にとっては「買い」です。評価は星4.5。特に「BYOK（Bring Your Own Key）」スタイルを採用しており、自分のOpenAIやAnthropicのAPIキーを使える点が、月額サブスクリプションを増やしたくない層に刺さります。

一方で、すでにRaycastの有料プラン（AI機能）に課金している人や、ブラウザ上での作業が9割を超える人には、わざわざ別の常駐アプリを増やすメリットは薄いでしょう。Jotの真価は、特定のアプリに依存せず、OSのアクセシビリティ機能を介して「今、自分が文字を打っている場所」をAIエディタに変えてしまう体験にあります。

## このツールが解決する問題

従来のAI活用における最大のボトルネックは「コピペの往復」でした。例えば、Slackで打った文章を丁寧に直したい時、私たちは「テキストをコピー」→「ブラウザでChatGPTを開く」→「プロンプトを入力」→「生成結果をコピー」→「Slackに戻って貼り付け」という5つのステップを踏んでいます。この過程で集中力が削がれる「コンテキストスイッチ」が発生するのが、エンジニアやライターにとっての大きな損失です。

Jotはこの5ステップを「テキスト選択」→「ショートカットキー」→「実行」という2ステップに短縮します。技術的には、OSのクリップボード監視とシミュレート入力を組み合わせることで、あたかもエディタ自体にAIが内蔵されているかのような挙動を実現しています。これは、エディタを問わない「ユニバーサルなAI機能」の提供と言えます。

## 実際の使い方

### インストール

公式サイトまたはProduct Hunt経由で入手したインストーラーを展開し、アプリケーションフォルダへ移動します。

```bash
# Homebrewでのインストールを想定（公式対応が確認されている場合）
brew install --cask jot
```

インストール後、最も重要なステップが「アクセシビリティ（アクセシビリティ権限）」の許可です。Jotは他のアプリのテキストを取得・置換するためにこの権限を必要とします。システム設定から「プライバシーとセキュリティ」→「アクセシビリティ」でJotを有効にしてください。これを忘れると「ショートカットを押しても反応しない」という、初期ユーザーが最も陥りやすいトラブルに遭遇します。

### 基本的な使用例

Jotを起動し、設定画面でOpenAIのAPIキー（`sk-...`）を入力します。デフォルトでは `Cmd + Shift + J` などのホットキーが割り当てられています。

例えば、適当なエディタで以下のテキストを選択した状態でJotを起動します。

```text
今日の会議の議事録を送ります。決定事項はAとBです。
```

Jotの入力窓に「敬語を丁寧に」と打ち込んでエンターを押すと、数秒で選択範囲が以下のテキストに自動で書き換わります。

```text
本日の会議の議事録を送付いたします。協議の結果、決定事項はAおよびBとなりましたので、ご確認いただけますと幸いです。
```

この「その場で書き換わる」感覚は、一度体験すると元には戻れません。

### 応用: 実務で使うなら

エンジニアとしての実務で役立つのは、やはりコードドキュメントの生成やリファクタリングの指示です。Jotはプロンプトのプリセットを自作できるため、あらかじめ「Pythonのdocstring生成用」などのテンプレートを作っておくと威力を発揮します。

以下は、Jotのカスタムスクリプト設定（YAML形式の想定）で定義するプロンプト例です。

```yaml
# jot_custom_prompts.yaml
prompts:
  docstring_gen:
    label: "Docstring生成"
    model: "gpt-4o"
    system_prompt: "あなたは熟練のPythonエンジニアです。選択された関数に対してGoogleスタイルのdocstringを生成し、コードに付与して返してください。"
    temperature: 0.2
```

この設定を読み込ませておけば、関数名を選択して「Docstring生成」を選ぶだけで、一瞬でコードが整備されます。VS Codeの拡張機能を入れるまでもない、ちょっとしたスクリプトを編集している時に非常に重宝します。

## 強みと弱み

**強み:**
- 圧倒的なレスポンスの速さ: 余計なUIを介さず、APIに直結しているため、ChatGPTのWeb画面より体感で1秒以上速く処理が始まります。
- どんなアプリでも動作する: Slack、Notion、Terminal、VS Code、果てはブラウザのテキストエリアまで、テキストが打てる場所ならどこでもAI化できます。
- 従量課金によるコスト最適化: 月額$20を払うほどではないが、たまに高品質なモデル（GPT-4oやClaude 3.5 Sonnet）を使いたい場合に、API利用料（月数十円〜数百円程度）だけで運用できます。

**弱み:**
- 権限設定のハードル: セキュリティが厳しい社用PCでは、アクセシビリティ権限の許可が下りない可能性があります。
- UIの簡素さ: チャット形式で何度もやり取りする用途には向いていません。あくまで「一発変換」がメインです。
- 英語ベース: インターフェースは英語のみです。日本語の処理自体はモデルに依存するので問題ありませんが、設定に戸惑うかもしれません。

Raycast AIは非常に洗練されていますが、月額サブスクリプションが必須です。一方でJotは「自分のAPIキーを使いたい」というエンジニア気質なユーザーに最適化されています。

## 料金・必要スペック・導入前の注意点

Jot自体の価格は、現在はProduct Huntでのローンチ直後ということもあり、基本無料または少額の買い切りモデルが予想されます。重要なのは、別途OpenAIやAnthropicのAPIキーが必要になる点です。

必要スペックについては、軽量なネイティブアプリであるため、M1以降のMacであればメモリ消費も微々たるものです（私の環境では50MB程度）。ただし、常にバックグラウンドでキー入力を監視するため、極端にリソースが不足している環境では、わずかな入力遅延を感じる可能性があります。

導入前の注意点として、APIの利用料を自分で管理する必要があります。特にGPT-4系を多用すると、気づかないうちに数ドル消費していることがあるため、OpenAI側でUsage Limit（利用上限設定）をかけておくことを強く推奨します。

## 私の評価

星5満点中、★4.2です。

「AIをツールとして使う」のではなく「OSの一部として溶け込ませる」という設計思想が素晴らしい。私はRTX 4090を積んだ自宅サーバーでローカルLLM（Llama 3など）を動かしていますが、このJotのインターフェースからローカルのAPIエンドポイントに接続できるか試したところ、設定次第で可能でした。これにより、プライバシーを重視するプロジェクトではローカルLLM、速度重視の時はGPT-4oといった使い分けが、OSレベルのショートカット一つで完結します。

万人におすすめできるツールではありませんが、テキスト入力が仕事の5割を超えるエンジニア、PM、ライターにとっては、1日あたり数十分の「コピペ時間」を削減できる、投資価値の高いツールになると確信しています。

## よくある質問

### Q1: セキュリティ面は大丈夫ですか？入力内容が開発者に送信されますか？

Jot自体は、あなたが設定したAPIエンドポイント（OpenAI等）に直接リクエストを送信する設計になっています。中間サーバーでテキストを保存しないことを売りにしていますが、BYOKモデルである以上、APIキーの管理は自己責任となります。

### Q2: Windows版はありますか？

現在のところ、Mac OS専用として開発されています。Windowsで同様のことを実現したい場合は「PowerToys」の機能拡張や、AutoHotkeyを用いた自作スクリプトが代替案となりますが、Jotほどのスムーズな挙動を構築するのは骨が折れるでしょう。

### Q3: 日本語のプロンプトもしっかり理解してくれますか？

はい。Jotは単なる「器」であり、知能の本体はGPT-4やClaudeなどのLLMです。そのため、日本語での指示や、日本語文章の校正・変換については、現在最高峰のAI精度をそのまま享受できます。
